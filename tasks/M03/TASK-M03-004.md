## Objective
`CrowdModel` في المحاكاة يُرجع لكل (مكان، يوم، دقيقة) كثافة زحام حتمية بالألف (0..1000) وفئتها، من منحنى زحام محيط لكل مكان + عدد الشخصيات الحاضرة فعلاً، ليقرأها حساب الشهود، مع عارض اختياري لعابرين بصريين لا يشهدون.

## Description
الشهود يُحسبون "بحسب مدى الرؤية، والمسافة، والانتباه، والزحام، وسمة observant" (FR-P1)؛ هذه المهمة تزوّد [TASK-M05-001](../M05/TASK-M05-001.md) بمدخل الزحام. السوق "زحام يتغير مع ساعات النهار" ([PRD 5.1](../../docs/PRD.md#51-الأماكن)). الزحام يقلل انتباه الشهود المسمَّين لكنه لا يخلق شهوداً: العابرون المحيطون ليسوا شخصيات ذات ذاكرة، فلا ينشؤون معتقدات (FR-M1). بذلك يبقى "الغش دون أن يكتشفه أحد" ممكناً (FR-P4).

## Implementation Plan
1. توسيع `Content/World/locations.json` ([TASK-M02-011](../M02/TASK-M02-011.md)) بحقل اختياري `ambientCrowd`: مصفوفة `{ "start": 360, "level": 300 }` (دقيقة اليوم، كثافة بالألف)، دالة درجية مرتبة. مثال السوق: 05:00=50، 07:00=300، 10:00=700، 13:00=450، 16:00=650، 19:00=150، 21:00=0.
2. `Simulation/Core/CrowdModel.cs`:
   - `AmbientAt(locationId, minuteOfDay)`: قيمة الدرجة الحالية (بلا استيفاء، أعداد صحيحة).
   - `PresentNpcs(locationId)`: من `NpcRegistry.NpcsAt` ([TASK-M03-002](../M03/TASK-M03-002.md)) مع استبعاد `Offmap` و`Home`.
   - `DensityAt(locationId, day, minuteOfDay) = min(1000, ambient + presentCount × npcWeight)` حيث `npcWeight` = 60 (إعداد).
   - `BandOf(density)`: `Empty` (<100)، `Light` (<350)، `Busy` (<700)، `Packed`.
3. الأماكن الفرعية ترث منحنى الأب إن لم يكن لها منحنى (الدكان يرث السوق).
4. لا حالة: `CrowdModel` دالة من البيانات الثابتة وحالة `NpcRegistry`، فلا تدخل اللقطة.
5. Runtime (عرض فقط): `Runtime/NPC/AmbientCrowdView.cs` يُنشئ عدداً من الكبسولات الرمادية العابرة = `density / 100` لكل مكان عام قرب اللاعب، تتحرك على NavMesh بمولد Runtime محلي غير محفوظ (بذرته من معرّف المكان)، فلا تمس `RngStreams` ولا اللقطة، بلا Collider تفاعل، وتختفي عند ابتعاد اللاعب > 40م.
6. لوحة Debug تعرض الكثافة والفئة للمكان الحالي.

## Acceptance Criteria
- [ ] `DensityAt` يعطي القيمة نفسها لنفس المدخلات في كل تشغيل، وهو دالة بلا آثار جانبية.
- [ ] السوق 10:00 بلا شخصيات = 700 (`Packed`)، و13:00 = 450 (`Busy`)، و21:00 = 0 (`Empty`).
- [ ] وجود 3 شخصيات في المكان يرفع الكثافة 180، والقيمة لا تتجاوز 1000.
- [ ] المكان الفرعي بلا منحنى يرث منحنى أبيه.
- [ ] العابرون البصريون لا يظهرون في `NpcRegistry` ولا في أي `witnessIds`، ولا يستهلكون من تيارات المحاكاة (اختبار: لقطة المحاكاة متطابقة مع العارض وبدونه).
- [ ] الواجهة `DensityAt` و`BandOf` موثقة لاستخدام [TASK-M05-001](../M05/TASK-M05-001.md).

## Objective
سجل واحد لتراخيص الطرف الثالث يغطي كل حزمة في PRD 8.1، والخطين المرشحين للعربية والرسم العثماني، وملف المصحف Tanzil، مع قاعدة: لا يدخل المستودع أصل أو حزمة بلا صف في السجل.

## Description
اللعبة مجانية وتُنشر للأطفال (S13)، لكن التوزيع المجاني لا يُسقط شروط التراخيص (الإسناد، وعدم التعديل، والأسماء المحجوزة). خط مجمع الملك فهد "تُراجع رخصته" بنص PRD 8.3، وملف Tanzil له شروط نسخ حرفي وإسناد مرفقة به. السجل شرط لـ [TASK-M01-003](../M01/TASK-M01-003.md) (الحزم)، و[TASK-M01-019](../M01/TASK-M01-019.md) (الخطوط)، و[TASK-M01-027](../M01/TASK-M01-027.md) (المصحف)، و[TASK-M02-004](../M02/TASK-M02-004.md) (شخصية مؤقتة).

## Implementation Plan
1. إنشاء `docs/THIRD_PARTY_LICENSES.md` بجدول أعمدته: `component`، `kind` (package/font/data/asset/tool)، `version`، `sourceUrl`، `license` (معرّف SPDX إن وُجد)، `licenseFile` (مسار نسخة الرخصة في المستودع)، `obligations` (إسناد، عدم تعديل، اسم محجوز، شاشة شكر)، `distributionOk` (yes/no/pending)، `status` (verified/pending/rejected)، `verifiedBy`، `date`.
2. صفوف أولية بحالة `pending` حتى يقرأ أحد الفريق نص الرخصة فعلاً:
   - Unity 6 Editor (شروط خطة Personal/Pro)، URP، Input System، Cinemachine، AI Navigation، Localization، Test Framework، Newtonsoft JSON (`com.unity.nuget.newtonsoft-json`)، TextMeshPro (ضمن uGUI).
   - Yarn Spinner for Unity، وRTLTMPro (مرشح اختبار B).
   - Amiri Quran، وخط مجمع الملك فهد للرسم العثماني، وخط واجهة عربي مرشح (يُحدد في [TASK-M01-019](../M01/TASK-M01-019.md)).
   - نص المصحف من Tanzil (الإصدار العثماني): الالتزام بنص الرخصة المرفق في رأس الملف كما هو.
   - أدوات CI إن اختيرت (GameCI actions).
   - أصول مؤقتة مرشحة لـ M02 (شخصية وحركات): صف لكل مصدر قبل تنزيله.
3. قسم "قبل إضافة أي حزمة أو أصل": أضف الصف أولاً، واحفظ نص الرخصة في `licenseFile` بجانب الأصل (مثل `Fonts/<Family>/OFL.txt`)، ولا تدمج قبل `status=verified`.
4. قسم الالتزامات المجمعة: ما يجب أن يظهر في شاشة الشكر داخل اللعبة (يُنفَّذ في M10/M13).
5. إضافة الرابط في `README.md`.

## Objective
واجهة `IDialogueProvider` وتنفيذها `RuleDialogueProvider` فوق `LineSelector` و`LineHistory`، كنقطة الدخول الوحيدة للـ barks والصوتين الداخليين، وجاهزة لبديل مستقبلي يعيد الصياغة فقط.

## Description
[PRD 8.2](../../docs/PRD.md): الواجهة مسموحة لأن لها بديلاً متوقعاً (قواعد الآن ثم ذكاء اصطناعي). [PRD 8.4](../../docs/PRD.md): "يستقبل السياق ويُرجع سطراً معتمداً"، وأي مزود مستقبلي يعيد صياغة سطر معتمد فقط، ويُمنع من توليد آيات أو أحاديث أو أحكام أو أحداث قصص. لا شبكة في MVP (S13)، فلا يُبنى المزود البديل الآن. المستهلكون: [TASK-M03-009](../M03/TASK-M03-009.md) (barks)، و[TASK-M06-003](../M06/TASK-M06-003.md) (محفزات الصوتين).

## Implementation Plan
1. `public interface IDialogueProvider { DialogueResult Provide(DialogueRequest request); }`.
2. `DialogueRequest { string speakerId; string pool; string trigger; FactSet facts; long now }`، و`DialogueResult { string lineId; string textKey; string audioKey; IReadOnlyDictionary<string,string> args }` أو `null`. الناتج مفاتيح فقط؛ الحل إلى نص في Runtime.
3. `RuleDialogueProvider(IReadOnlyList<LineDef> lines, LineHistory history, SeededRng presentationRng, Func<long> clock)`:
   - يبني `LineQuery` ويستدعي `LineSelector.Select`.
   - عند النجاح يستدعي `history.MarkSaid` في الموضع نفسه (نقطة واحدة لتسجيل المقول، كي يصح T6).
4. ملاحظة تصميم في [docs/systems/DIALOGUE.md](../../docs/systems/DIALOGUE.md): المزود المستقبلي `AiParaphraseProvider` يغلّف `RuleDialogueProvider` ويمرر ناتجه على `OutputFilter` يرفض أي آية أو حديث أو حكم أو حدث قصة ويعود للسطر الأصلي؛ لا يُكتب له كود الآن.
5. لا واجهة أخرى: الفلتر والمزود البديل غير موجودين حتى P6.

## Acceptance Criteria
- [ ] `Provide` يرجع السطر نفسه الذي يختاره `LineSelector` للمدخلات نفسها.
- [ ] بعد `Provide` ناجح يظهر السطر في `LineHistory` بوقت `now`، ولا يُرجع مرة ثانية أثناء مهلته.
- [ ] لا مطابق ولا سطر عام ← `null` دون تغيير `LineHistory`.
- [ ] الناتج لا يحوي نصاً، بل مفاتيح ومتغيرات فقط.
- [ ] `IDialogueProvider` لا يعرف `UnityEngine` ولا Yarn.

## Objective
مشروع Unity 6 (إصدار LTS محدد) بقالب URP في `unity/`، بإعدادات Force Text وVisible Meta Files، يفتح بلا أخطاء، ومحفوظ في git بلا ملفات مولَّدة.

## Description
أول مخرجات P0 ([PRD 11](../../docs/PRD.md)): "مشروع Unity 6 مع URP". القرار [D-001](../../planning/DECISIONS.md) (Unity 6 + URP، macOS أولاً) و[D-012](../../planning/DECISIONS.md) (المشروع في `unity/`). كل مهام M01 تقريباً تبدأ من هنا، وهي على المسار الحرج.

## Implementation Plan
1. تثبيت Unity 6 LTS عبر Unity Hub مع الوحدات: macOS Build Support (IL2CPP)، WebGL Build Support، Android Build Support (أو iOS حسب [TASK-M00-008](../M00/TASK-M00-008.md)). يُسجل رقم الإصدار الكامل (`6000.x.yf1`) في Notes و`README.md`.
2. إنشاء مشروع من قالب "Universal 3D" في `unity/` مباشرة.
3. Project Settings:
   - Editor → Asset Serialization: **Force Text**؛ Version Control: **Visible Meta Files**.
   - Player: Product Name مؤقت، Company Name، Bundle Identifier ثابت (`com.<org>.islamicgame`) يُسجل في Notes؛ Color Space: Linear؛ Api Compatibility: .NET Standard 2.1.
   - Scripting Backend: Mono للمحرر، IL2CPP لبناءات macOS/WebGL/الجوال (يُضبط في [TASK-M01-005](TASK-M01-005.md)).
4. حذف محتوى القالب التعليمي (`TutorialInfo`، `Readme.asset`، المشهد التجريبي) وإنشاء `Assets/_Project/Scenes/Boot.unity` فارغاً كمشهد أول في Build Settings.
5. URP: أصلان في `Assets/_Project/Settings/`: `URP_Mac_Medium` و`URP_Low` (للويب والجوال)، وربطهما بمستويات Quality.
6. التحقق من `.gitignore` ([TASK-M00-002](../M00/TASK-M00-002.md)) ثم commit: `TASK-M01-001: Unity 6 URP project`.

## Expected Files
- `unity/ProjectSettings/*` (ومنها `ProjectVersion.txt`)
- `unity/Packages/manifest.json` و`unity/Packages/packages-lock.json`
- `unity/Assets/_Project/Scenes/Boot.unity`
- `unity/Assets/_Project/Settings/URP_Mac_Medium.asset` و`URP_Low.asset` (مع Renderer)
- `README.md` (إصدار Unity المطلوب)

## Acceptance Criteria
- [ ] فتح المشروع في Unity على Mac نظيف يعطي Console بلا أخطاء.
- [ ] `head -1 unity/ProjectSettings/ProjectSettings.asset` = `%YAML 1.1` (Force Text)، و`EditorSettings.asset` يحوي Visible Meta Files.
- [ ] `ProjectVersion.txt` محفوظ، وإصدار Unity مذكور في README.
- [ ] `git status` بعد فتح المحرر وإغلاقه لا يُظهر `Library/` أو `Temp/` أو `Logs/` أو `UserSettings/`.
- [ ] Play على `Boot.unity` يعمل بلا أخطاء، ومستويا URP مربوطان بـ Quality.

## Testing
- يدوي: استنساخ نظيف في مجلد مؤقت، `git lfs install`، فتح المشروع، انتظار الاستيراد، التحقق من Console.
- `grep -c "m_SerializationMode: 2" unity/ProjectSettings/EditorSettings.asset` = 1.

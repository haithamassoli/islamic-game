## Objective
Unity Localization مهيأة بلغة العربية لغةً وحيدة وافتراضية، وجداول نصوص لكل مجال، واصطلاح مفاتيح موثق، وفحص آلي يمنع النصوص العربية الثابتة في الكود.

## Description
[PRD 7.14](../../docs/PRD.md): "كل النصوص بمفاتيح ترجمة من اليوم الأول (حزمة Unity Localization)، فتكون إضافة الإنجليزية لاحقاً بلا تعديل في الكود"، وAGENTS.md §4: لا نصوص عربية ثابتة داخل الكود. FR-C2 يحتاج متغيرات (`{npc}`، `{day}`) داخل السطور.

## Implementation Plan
1. Localization Settings: Locale `ar` وحيد، Startup Locale Selector ثابت على `ar` (لا اكتشاف لغة الجهاز في MVP).
2. String Table Collections في `Assets/_Project/Localization/`: `UI`، `World`، `Dialogue` (لسطور Yarn في [TASK-M01-028](TASK-M01-028.md))، `Barks`، `InnerVoice`، `Story`، `Journey`، `Endings`.
3. اصطلاح المفاتيح: `<domain>.<context>.<name>` بأحرف إنجليزية صغيرة وشرطة سفلية، مثل `ui.menu.new_game`، `world.town.name`، `bark.rival.greeting_01`، `iv.conscience.after_cheat_01`. سطور Yarn بمعرفاتها `line:<id>`.
4. Smart Strings مفعّلة للمتغيرات المسماة، وقواعد الجمع العربية (CLDR بستة أشكال) للأعداد.
5. اختبار EditMode `LocalizationConventionTests.AllKeys_MatchConvention` (regex على كل المفاتيح).
6. فحص `NoArabicLiteralsTests.NoArabicInCSharp`: يمسح كل `.cs` تحت `Assets/_Project/Scripts` بحثاً عن محارف في النطاقات U+0600–06FF، U+0750–077F، U+08A0–08FF، U+FB50–FDFF، U+FE70–FEFF ويفشل مع اسم الملف والسطر (يُستثنى ملف قائمة استثناءات صريح فارغ افتراضياً).
7. مفاتيح أولية: `world.town.name` (قيمة مؤقتة حتى [TASK-M00-005](../M00/TASK-M00-005.md))، و`ui.common.ok`، و`ui.common.cancel`.
8. قسم الاصطلاح في [docs/LOCALIZATION.md](../../docs/LOCALIZATION.md).

## Acceptance Criteria
- [ ] `LocalizationSettings.SelectedLocale` عند التشغيل = `ar`.
- [ ] الجداول الثمانية موجودة ومحفوظة كنص (Force Text).

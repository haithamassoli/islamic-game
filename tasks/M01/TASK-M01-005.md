## Objective
`BuildScripts` في Editor تبني تطبيق macOS من سطر الأوامر بكود خروج صحيح وتقرير بناء، وبهيكل قابل لإضافة WebGL والجوال في [TASK-M01-017](TASK-M01-017.md) و[TASK-M01-018](TASK-M01-018.md).

## Description
PRD 11 (P0): "بناء macOS". البناء من سطر الأوامر شرط لتكرار القياس، وللإصدار في [TASK-M13-008](../M13/TASK-M13-008.md)، ولبوابة المحتوى الديني [TASK-M01-026](TASK-M01-026.md) التي تعمل كـ pre-build في وضع الإصدار.

## Implementation Plan
1. `Editor/Build/BuildScripts.cs` (namespace `IslamicGame.Editor.Build`):
   - `public static void BuildMacOS()` تُستدعى بـ `-executeMethod IslamicGame.Editor.Build.BuildScripts.BuildMacOS`.
   - قراءة الوسائط: `-buildOutput <path>` (افتراضي `Builds/macOS/`)، `-development`، `-release`، `-buildVersion <x.y.z>`.
   - المشاهد من `EditorBuildSettings.scenes` المفعّلة؛ فشل فوري إن كانت فارغة.
   - `BuildPlayerOptions`: `BuildTarget.StandaloneOSX`، معمارية Apple Silicon + Intel، IL2CPP.
   - `-release` يضيف `IG_RELEASE` عبر `extraScriptingDefines`؛ غيابه يضيف `IG_DEV`. (يعتمد عليهما [TASK-M08-002](../M08/TASK-M08-002.md) وبوابة [TASK-M01-026](TASK-M01-026.md)).
   - بعد البناء: كتابة `build_report.txt` (النتيجة، المدة، الحجم الكلي، عدد التحذيرات والأخطاء) و`EditorApplication.Exit(0|1)`.
2. دالة داخلية مشتركة `Build(BuildTarget, string defaultOutput, Action<BuildPlayerOptions> configure)` تعيد استخدامها WebGL والجوال.
3. `tools/build_macos.sh`: يجد مسار Unity من `ProjectVersion.txt` ويشغّل `-batchmode -quit -projectPath unity -executeMethod ... -logFile Builds/macOS/build.log`.
4. توقيع ad-hoc فقط في P0؛ التوقيع والتوثيق في [TASK-M13-008](../M13/TASK-M13-008.md).

## Expected Files

## Acceptance Criteria
- [ ] `tools/build_macos.sh` ينتج `.app` بكود خروج 0 على Mac M1.
- [ ] التطبيق يفتح (بعد فتح يدوي أول مرة) ويعرض `Boot.unity` بلا أخطاء في سجل المشغل.
- [ ] خطأ ترجمة مقصود أو قائمة مشاهد فارغة يعطي كود خروج ≠ 0.
- [ ] `build_report.txt` يحوي النتيجة والمدة والحجم.
- [ ] بناء `-release` يعرّف `IG_RELEASE` وبناء التطوير يعرّف `IG_DEV` (يُتحقق بسطر سجل عند الإقلاع).

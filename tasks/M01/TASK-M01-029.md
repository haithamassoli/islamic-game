## Objective
`LineSelector` نقي حتمي يختار سطراً من قاعدة `LineDef` بمطابقة الشروط على `FactSet`، بالأولوية، مع المهلة و`once`، والسطر العام عند غياب المطابق، و`LineHistory` قابل للحفظ.

## Description
[PRD 7.10](../../docs/PRD.md) FR-D2 (محدد قواعد يقرأ JSON)، FR-D3 (الحقائق من المعتقدات والعلاقة والسجل الأخلاقي والوقت والمكان والقصة)، FR-D4 (طباع الشخصية تحدد المجموعة)، FR-D5 (لا تكرار أثناء المهلة، وسطر عام عند غياب المطابق)؛ وFR-C1 للصوتين الداخليين. FR-S1: السطور المقولة ومهلاتها في الحفظ، وT6: سطر `once` لا يتكرر بعد التحميل. المستهلكون: [TASK-M01-030](TASK-M01-030.md)، و[TASK-M03-008](../M03/TASK-M03-008.md) (مزود الحقائق)، و[TASK-M03-010](../M03/TASK-M03-010.md) (حفظ السطور).

## Implementation Plan
1. `FactSet`: قاموس مرتب Ordinal `string → FactValue` (عدد صحيح، أو منطقي، أو نص معرّف)؛ لا أعداد عشرية. أسماء الحقائق نقطية (`belief.player.cheated`، `rel.trust`، `time.minute`).
2. `LineHistory`: `SortedDictionary<string,long> lastSaidAt` (بالدقائق)، و`SortedSet<string> onceSaid`؛ `MarkSaid(lineId, now, once)`؛ `ToState()`/`FromState()`.
3. `LineSelector.Select(LineQuery q)` حيث `LineQuery { string speaker; string pool; FactSet facts; long now; IReadOnlyList<LineDef> lines; LineHistory history; SeededRng rng }`:
   1. ترشيح بالمتحدث والمجموعة.
   2. استبعاد `once` المقول، وما مهلته سارية (`now - lastSaidAt < cooldown`).
   3. تطابق كل الشروط (`eq, ne, gt, ge, lt, le, has, not_has`)؛ حقيقة مفقودة = عدم تطابق (عدا `not_has`).
   4. استبعاد سطر ينقصه متغير من `vars[]` في `FactSet` (FR-C2).
   5. الأعلى `priority`؛ ثم الأكثر شروطاً؛ ثم اختيار بـ `rng` (تيار `presentation`) بين المتساوين بعد ترتيبهم بالمعرف.
   6. لا مطابق ← السطور `generic=true` للمتحدث/المجموعة بالقواعد 2 و4 نفسها؛ لا شيء ← `null` (صمت).
4. الناتج `LineSelection { LineDef line; IReadOnlyDictionary<string,string> args }` (قيم المتغيرات نصاً بـ InvariantCulture، والتنسيق للعرض في Runtime).
5. المحدد لا يرشح بحالة المراجعة: يستقبل قائمة سطور مرشحة سلفاً بـ `ContentGate` في بناء الإصدار ([TASK-M01-026](TASK-M01-026.md)).

## Acceptance Criteria
- [ ] سطر بشرطين يُختار فقط إن تحقق الشرطان معاً.
- [ ] بين سطرين مطابقين يُختار الأعلى `priority` دائماً.
- [ ] سطر بمهلة 60 دقيقة لا يُختار عند `now = lastSaid + 59` ويُختار عند `+60`.
- [ ] سطر `once` لا يُختار مرة ثانية، ولا بعد `FromState(ToState())`.
- [ ] عند غياب المطابق يُرجَع سطر `generic`، وعند غيابه `null`.
- [ ] سطر ينقصه متغير لا يُختار.
- [ ] بذرة واحدة ومدخلات واحدة = الاختيار نفسه في 100 تكرار.
- [ ] اختيار من 1000 سطر يستغرق ≤ 0.5 ms على Mac M1 (متوسط 1000 استدعاء).

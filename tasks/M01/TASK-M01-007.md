## Objective
`SeededRng` مولد عشوائي حتمي بحالة قابلة للحفظ، و`RngStreams` بتيارات مسماة مستقلة مشتقة من البذرة الرئيسية، بديلاً عن `System.Random` و`UnityEngine.Random` في كل المحاكاة ([D-011](../../planning/DECISIONS.md)).

## Description
FR-E6: "العشوائية من مولد ببذرة ثابتة تُحفظ حالته مع اللعبة"، وFR-S1 يضع حالة المولد في اللقطة، وT3/T5 تتطلب تطابق التشغيل مع حفظ وتحميل في المنتصف وبدونه. `System.Random` لا تُحفظ حالته ويختلف بين أنظمة .NET. القاعدة 2 في [TECHNICAL_ARCHITECTURE §7](../../docs/TECHNICAL_ARCHITECTURE.md): تيارات مسماة كي لا يزيح مستهلك جديد تسلسل الآخرين.

## Implementation Plan
1. `SeededRng` بخوارزمية PCG32 (XSH-RR): حالة `ulong state` و`ulong inc`. العمليات:
   - `uint NextUInt()`.
   - `int NextInt(int minInclusive, int maxExclusive)` بلا انحياز (طريقة Lemire مع الرفض).
   - `int NextPermille()` ← 0..999، و`bool Chance(int permille)` (الاحتمالات بالألف حسب القاعدة 4).
   - `void Shuffle<T>(IList<T>)` (Fisher–Yates)، و`T Pick<T>(IReadOnlyList<T>)`.
   - لا `NextDouble` ولا `float` (حالة المحاكاة أعداد صحيحة).
2. `RngState { ulong state; ulong inc }` مع `ToState()`/`FromState()`.
3. `RngStreams`: قائمة ثابتة بالأسماء `perception`، `rumors`، `economy`، `customers`، `life`، `consequences`، `presentation`. بذرة كل تيار = SplitMix64(`masterSeed` XOR FNV-1a-64 لبايتات UTF-8 لاسم التيار). `Get(string name)` يرمي لاسم غير معروف؛ إضافة تيار جديد = سطر في القائمة لا يغيّر الآخرين.
4. `RngStreamsState { ulong masterSeed; SortedDictionary<string, RngState> streams }` (ترتيب Ordinal).
5. تيار `presentation` للعرض وحده، فلا يستهلك العرض من تيارات المحاكاة (القاعدة 7).

## Objective
بناء جوال لمشهد القياس على الجهاز المحدد في [TASK-M00-008](../M00/TASK-M00-008.md)، وقياسه بالبروتوكول نفسه مع الحرارة بعد 10 دقائق، ونتائج خام في `docs/reports/PERF_P0_MOBILE.md`.

## Description
PRD 11 (P0): "بناء تجريبي على ... جوال واحد". النتائج مدخل لتقرير [TASK-M01-023](TASK-M01-023.md) ولقرار P4 لاحقاً، والبناء نفسه يستخدمه اختبارا العربية. الجوال ليس منصة إطلاق في MVP ([PRD 3](../../docs/PRD.md))؛ الهدف إزالة المجهول.

## Implementation Plan
1. حسب اختيار المصفوفة (التوصية Android):
   - Android: `BuildScripts.BuildAndroid()`، IL2CPP، ARM64 فقط، APK للتطوير، Min API حسب الجهاز، Graphics API: Vulkan ثم OpenGLES3 احتياطاً، `URP_Low`.
   - iOS (بديل): `BuildScripts.BuildiOS()` يُخرج مشروع Xcode، والتوقيع بحساب الفريق.
2. التثبيت: `adb install -r` (أو Xcode)، والتشغيل والجهاز موصول بالشاحن.
3. القياس: سطر `PortabilityProbe` من `adb logcat -s Unity`، 3 تشغيلات والوسيط؛ الذاكرة من `adb shell dumpsys meminfo <package>`؛ الحرارة والإطارات بعد 10 دقائق تشغيل متواصل (`dumpsys thermalservice` أو ما يماثله)؛ حجم APK وحجم التثبيت.
4. بناء Development مع Profiler متصل لتشغيل واحد: أعلى 5 تكاليف CPU/GPU تُذكر نصاً.
5. ملاحظات تشغيلية: لمس بلا تحكم (غير مطلوب)، ونسبة الشاشة، وsafe area، والكتابة إلى `persistentDataPath`.

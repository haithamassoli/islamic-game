## Objective
تثبيت حزم PRD 8.1 بإصدارات مثبتة في `manifest.json` و`packages-lock.json`، ولكل حزمة صف في سجل التراخيص، والمشروع يُترجم بلا أخطاء.

## Description
[PRD 8.1](../../docs/PRD.md): Input System، وCinemachine، وNavMesh، وYarn Spinner، وUnity Localization؛ ومعها Newtonsoft JSON للحفظ القانوني ([D-005](../../planning/DECISIONS.md)) وTest Framework. Addressables لا تُضاف حتى وجود عالم ثانٍ. حزمة عرض النص العربي **لا** تُثبت هنا؛ تُجرَّب في [TASK-M01-020](TASK-M01-020.md) و[TASK-M01-021](TASK-M01-021.md).

## Implementation Plan
1. عبر Package Manager، بإصدارات محددة (لا `latest`): `com.unity.inputsystem`، `com.unity.cinemachine` (3.x)، `com.unity.ai.navigation`، `com.unity.localization`، `com.unity.nuget.newtonsoft-json`، `com.unity.test-framework`، و`com.unity.ugui` (TextMeshPro ضمنها في Unity 6).
2. Yarn Spinner for Unity: من سجل OpenUPM (scoped registry في `manifest.json`) أو رابط git بوسم إصدار؛ يُسجل المصدر والإصدار.
3. إزالة حزم القالب غير المستخدمة (Visual Scripting، Multiplayer Center، Collab…) بعد التحقق من عدم استخدامها.
4. Player → Active Input Handling = **Input System Package (New)**.
5. تحديث [سجل التراخيص](../M00/TASK-M00-003.md) بالإصدار الفعلي لكل حزمة.
6. اختبار EditMode دخان `PackageSmokeTests` يتأكد من حل الأنواع: `Newtonsoft.Json.JsonConvert`، `Yarn.Unity.DialogueRunner`، `UnityEngine.Localization.Settings.LocalizationSettings`، `Unity.Cinemachine.CinemachineCamera`، `Unity.AI.Navigation.NavMeshSurface`.

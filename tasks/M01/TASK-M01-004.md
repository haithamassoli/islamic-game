## Objective
CI على GitHub Actions يشغّل اختبارات EditMode آلياً على كل push وpull request، ومعها فحص `plan.py check` وفحص نقاء المحاكاة، بعد قرار مكتوب عن ترخيص Unity وبيئة التشغيل.

## Description
AGENTS.md §5: اختبارات الحفظ T1–T9 إلزامية في CI، وبوابة P0 ([PRD 11](../../docs/PRD.md)): "اختبارات الحفظ تنجح في CI". تشغيل Unity بلا واجهة يحتاج ترخيصاً مفعّلاً، وهذا قرار يُسجل لا افتراض. خطر "تشغيل Unity في CI على macOS" مذكور في [M01](../../milestones/M01.md) §8.

## Implementation Plan
1. **قرار بيئة CI** (يُكتب في [planning/DECISIONS.md](../../planning/DECISIONS.md) برقم القرار التالي المتاح) بين:
   - (أ) GameCI (`game-ci/unity-test-runner`) على Ubuntu بصورة Docker لإصدار Unity المثبت، مع أسرار `UNITY_LICENSE` أو `UNITY_EMAIL`/`UNITY_PASSWORD`/`UNITY_SERIAL` حسب نوع الترخيص.
   - (ب) جهاز macOS ذاتي الاستضافة (self-hosted runner) عليه Unity مرخص.
   المعايير: شروط ترخيص Unity لتفعيل CI، والكلفة، وزمن التشغيل، والتوفر، وأمان runner ذاتي على مستودع خاص. اختبارات EditMode للمحاكاة لا تعتمد على المنصة، فلينكس يكفي لها.
2. `.github/workflows/ci.yml` بثلاث وظائف:
   - `plan-check` (Ubuntu، ثوانٍ): `python3 tools/plan.py check` و`python3 tools/test_plan.py`.
   - `sim-purity` (Ubuntu): `tools/ci/check_sim_purity.sh` يفشل إن وجد `grep -rnE 'using UnityEngine|UnityEngine\.|System\.Random|DateTime\.(Now|UtcNow)|Environment\.TickCount|Guid\.NewGuid' unity/Assets/_Project/Scripts/Simulation`.
   - `editmode` : `actions/checkout` مع `lfs: true`، وcache لـ `unity/Library` بمفتاح من `packages-lock.json` و`ProjectSettings/ProjectVersion.txt`، وتشغيل EditMode، ورفع `results.xml` كـ artifact، وفشل الوظيفة عند أي اختبار فاشل.
3. `concurrency` يلغي التشغيل الأقدم على الفرع نفسه، و`timeout-minutes: 45`.
4. `tools/ci/run_editmode_local.sh`: يقرأ الإصدار من `ProjectVersion.txt` ويشغّل الأمر المحلي من AGENTS.md §5 ويعيد كود خروج صحيح.
5. الأسرار في GitHub Secrets فقط؛ لا ملف ترخيص (`.ulf`) في المستودع.
6. تفعيل حماية `main` (required checks) إن سمح نوع المستودع.

## Potential Issues
- تفعيل ترخيص Personal في CI تغيّر عبر الإصدارات: يُتبع توثيق GameCI للإصدار المثبت، والبديل (ب) جاهز.
- حصة LFS تُستهلك بسرعة مع `lfs: true` في كل تشغيل: cache لكائنات LFS، أو checkout بلا LFS لوظائف لا تحتاج الأصول.
- runner ذاتي على مستودع عام يسمح بتنفيذ كود من PR خارجي: المستودع خاص، أو تشغيل PR الخارجية يدوياً.
- استيراد المشروع الأول بطيء (دقائق): cache لـ `Library`.

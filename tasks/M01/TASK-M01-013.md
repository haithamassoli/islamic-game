## Objective
لقطة حفظ `SaveSnapshot` تجمع حالة النواة كاملة، و`SimulationWorld` يُنشأ جديداً أو من لقطة، و`SaveManager` يحفظ ويحمّل عند النقاط الآمنة فقط، عبر `ISaveStorage` بتنفيذ محلي يكتب ذرياً مع نسخة احتياطية و3 خانات وحفظ تلقائي.

## Description
[PRD 7.15](../../docs/PRD.md): FR-S1 (لقطة كاملة + السجل كاملاً)، FR-S2 (التحميل استعادة لا إعادة تنفيذ)، FR-S3 (لا حفظ أثناء خطوات FR-E4)، FR-S5 (ملف مؤقت ثم إعادة تسمية ذرية ونسخة احتياطية، حفظ تلقائي وعند النوم، 3 خانات)، FR-S6 (`ISaveStorage` محلي الآن وConvex لاحقاً). الأنظمة اللاحقة تضيف حقولها للقطة (مثل [TASK-M04-002](../M04/TASK-M04-002.md)، [TASK-M03-010](../M03/TASK-M03-010.md)، [TASK-M05-017](../M05/TASK-M05-017.md)).

## Implementation Plan
1. `SaveSnapshot` (حقول صريحة، لا أجزاء ديناميكية): `int schemaVersion`، `string gameVersion`، `ClockState clock`، `RngStreamsState rng`، `DecisionLogState log` (يشمل `nextSeq` والأحداث ومؤشرات المعالجات)، `ScheduledQueueState scheduled`. كل نظام لاحق يضيف حقلاً مسمى مع رفع الإصدار ([TASK-M01-014](TASK-M01-014.md)).
2. `SimulationWorld` (`Simulation/Core`): يملك `Clock`، `Rng`، `Log`، `Scheduled`، وقائمة المعالجات؛ `static CreateNew(ulong seed, long startMinute)`، `static Restore(SaveSnapshot)`، `SaveSnapshot ToSnapshot()`، `void Step()` (تقدم الساعة ثم الأحداث المستحقة)، `bool IsAtSafePoint`.
3. `public interface ISaveStorage { bool Exists(string key); string Read(string key); void WriteAtomic(string key, string content); IReadOnlyList<string> ListKeys(); void Delete(string key); }`.
4. `LocalFileSaveStorage(string rootDir)` (المسار يمرره Runtime من `Application.persistentDataPath`):
   - `WriteAtomic`: كتابة `<key>.tmp` + `Flush(true)` ← إن وُجد `<key>.json`: `File.Replace(tmp, json, <key>.bak)` وإلا `File.Move(tmp, json)`.
   - `Read`: يقرأ `.json`؛ إن فشل التحليل أو كان مبتوراً يعود إلى `.bak` ويبلغ عن ذلك.
   - عند الإنشاء: حذف أي `.tmp` يتيم.
   - نقطة حقن عطل `internal Action<string> BeforeReplace` للاختبارات (T8).
5. `SaveManager(ISaveStorage)`: خانات `slot1..slot3` و`auto`؛ `bool CanSave(SimulationWorld w) => w.IsAtSafePoint`؛ `SaveResult Save(world, slot)` يرفض عند عدم الأمان؛ `SimulationWorld Load(slot)`؛ `Autosave(world)` يستدعيه Runtime دورياً وعند النوم. البيانات الوصفية للخانة (التاريخ الحقيقي، اليوم في اللعبة) في ملف `<slot>.meta.json` منفصل خارج اللقطة كي لا تكسر T1.
6. الاستعادة تبني الحالة مباشرة من اللقطة: لا استدعاء لمعالج ولا `OnRecorded` ولا سطر حوار (FR-S2).

## Acceptance Criteria
- [ ] `Save` أثناء `IsProcessing` (من داخل معالج تجسس) يُرفض ولا يكتب أي ملف.
- [ ] بعد التحميل: `nextSeq` وعدد الأحداث ومؤشرات المعالجات وعناصر الطابور وحالة كل تيار عشوائي مطابقة لما قبل الحفظ.
- [ ] التحميل لا يستدعي أي `Handle` ولا أي مشترك `OnRecorded` (عدادات التجسس = 0).
- [ ] الحفظ الثاني في الخانة نفسها ينشئ `.bak` بمحتوى الحفظ الأول.
- [ ] ملف `.json` مبتور يُحمَّل بدلاً منه `.bak` مع تقرير.
- [ ] ثلاث خانات يدوية وخانة تلقائية مستقلة؛ البيانات الوصفية خارج اللقطة.
- [ ] لا `UnityEngine` في أي ملف من الملفات أعلاه.

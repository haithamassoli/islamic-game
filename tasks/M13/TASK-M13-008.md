## Objective
بناء إصدار MVP لـ macOS موقّع بـ Developer ID وموثّق (notarized) ومدبّس (stapled) في DMG، يجتاز قائمة إصدار نهائية تضم كل أدلة PRD 12، وجاهز للتوزيع المجاني بالعربية (PRD 11، P3).

## Description
بوابة P3: "إصدار مجاني على macOS بالعربية". Gatekeeper يمنع تشغيل التطبيقات غير الموثقة للمستخدم العادي، فالتوقيع والتوثيق شرط. القائمة تجمع الأدلة: T1–T9 (TASK-M13-001)، والأداء (TASK-M13-002)، والقائمة الدينية الموقعة (TASK-M13-004)، والمسائل المعلقة (TASK-M13-005)، وإصلاحات الاختبار (TASK-M13-007). S13: لا إعلانات ولا مشتريات ولا شبكة ولا جمع بيانات.

## Implementation Plan
1. أمر `BuildRelease` (توسيع `BuildVerticalSlice` من TASK-M11-008): `IG_RELEASE`، واستبعاد لوحة التطوير وسجل نسخة الاختبار (TASK-M13-006) ومدقق الاتساق، و`build_info.json` بالإصدار `1.0.0` وgit SHA وبصمة القائمة الدينية.
2. بوابات البناء: البوابة الدينية (FR-Q2)، و`PendingRegisterTests`، وتطابق بصمة القائمة مع توقيع TASK-M13-004، و`VoiceHashCheck`؛ أي فشل يوقف البناء.
3. هدف المعمارية: Universal (Apple Silicon + Intel) أو Apple Silicon فقط، بقرار مكتوب (الهدف المعلن M1).
4. التوقيع: `codesign --deep --options runtime --timestamp` بشهادة Developer ID Application، مع ملف entitlements أدنى (Hardened Runtime) دون صلاحيات شبكة أو كاميرا أو ميكروفون.
5. التوثيق: `xcrun notarytool submit --wait`، ثم `xcrun stapler staple` على التطبيق والـ DMG.
6. DMG بخلفية عربية بسيطة وملف "اقرأني" قصير، وبصمة SHA-256 منشورة مع الملف.
7. قناة التوزيع المجاني: موقع المشروع أو منصة توزيع مجانية لا تفرض إعلانات أو حسابات على اللاعب (قرار في DECISIONS)؛ Mac App Store خارج MVP لاشتراط Sandbox ومراجعة إضافية (يعاد النظر لاحقاً).
8. قائمة الإصدار `RELEASE_CHECKLIST.md`: كل بنود PRD 12 مع روابط الأدلة، وفحص الشبكة بـ `nettop`، وفحص Gatekeeper `spctl -a -vv`، وتشغيل على جهاز نظيف، وتشغيل على حساب macOS بلغة عربية وأخرى إنجليزية (ثقافة الجهاز لا تغير الحفظ).

- [ ] `spctl -a -vv` يقبل التطبيق بـ "Notarized Developer ID" على جهاز نظيف، والتطبيق يفتح دون تحذير.
- [ ] `stapler validate` ينجح على التطبيق والـ DMG.
- [ ] البناء يفشل عند تعطيل أي بوابة (تجربة سلبية لكل من البوابات الأربع).
- [ ] صفر اتصالات شبكة خلال 15 دقيقة لعب، ولا إذن نظام يُطلب.
- [ ] كل بنود PRD 12 في القائمة لها دليل مرتبط ونتيجة؛ أي بند راسب له قرار إطلاق مكتوب من مالك المنتج.
- [ ] الحفظ يعمل في مجلد المستخدم الصحيح، وحذف التطبيق لا يحذف الحفظ دون علم (موثق في صفحة الخصوصية).

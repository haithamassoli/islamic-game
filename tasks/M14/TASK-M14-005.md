## Objective
تدقيق جاهزية الترجمة الإنجليزية لبناء MVP: صفر نصوص ثابتة في الكود، وكل سطر Yarn وكل نص UI بمفتاح، وقدرة الواجهة على التبديل إلى LTR، وتقرير بالفجوات مع مهام إصلاح، دون كتابة أي ترجمة.

## Description
PRD 7.14: "كل النصوص بمفاتيح ترجمة من اليوم الأول (حزمة Unity Localization)، فتكون إضافة الإنجليزية لاحقاً بلا تعديل في الكود". P5: الإنجليزية مع مراجعة شرعية للترجمات. AGENTS.md: لا نصوص عربية ثابتة داخل الكود. التدقيق يثبت أن هذا تحقق فعلاً قبل بدء P5.

## Implementation Plan
1. فحص آلي للكود: `HardcodedStringScan` (أداة Editor) يبحث في `Scripts/` عن سلاسل تحوي حروفاً عربية، وعن سلاسل تُمرر لخصائص نص UI (`text =`، `Label`) خارج نظام الترجمة؛ مع قائمة استثناءات موثقة (مفاتيح، معرّفات).
2. فحص Yarn: كل سطر له `#line:` ومدخل في الجدول؛ صفر أسطر بلا وسم.
3. فحص الجداول: كل مفتاح مستخدم موجود، ولا مفاتيح يتيمة؛ إنشاء لغة `en` تجريبية بنصوص placeholder آلية (`[EN] key`) لتشغيل اللعبة كاملة بها.
4. التخطيط: تشغيل الواجهة بـ `en` والتأكد أن اتجاه التخطيط يتبع اللغة (لا RTL ثابت في الأنماط)، ولقطات للشاشات الرئيسية.
5. المتغيرات والقواعد: مراجعة المتغيرات التي تفترض قواعد العربية (التذكير والتأنيث، والجمع) واستخدام Smart Strings أو صيغ الجمع حيث لزم.
6. المحتوى الديني: قائمة بكل البنود التي ستحتاج ترجمة معتمدة ومراجعة شرعية في P5 (السرد، والضمير، والنهايات، والدروس)، مع ملاحظة أن الآيات تُعرض بنصها العربي المستخرج وترجمة المعاني تحتاج مصدراً معتمداً منفصلاً.
7. التقرير وقائمة مهام الإصلاح.

## Objective
تسجيل عربي كامل ونظيف ومدمج: الراوي لمقاطع القصة الأربعة، والصوتان الداخليان لكل سطورهما المعتمدة، والسطور الرئيسية (`#main`) للشخصيات، مرتبطاً كل ملف بنسخة النص المعتمدة عبر البصمة (FR-Q3)، دون أي صوت للأنبياء (S1) ودون معازف (S11).

## Description
P3 (PRD 11) يتطلب "التسجيل العربي الكامل". FR-C5: الصوتان بصوتين مسجلين مختلفين مع ترجمة دائمة. S1: لا صوت للنبي؛ كلامه يظهر آيات فقط. FR-N2: "التلاوة مسجلة اختيارياً"، وهي محتوى ديني يحتاج اعتماداً مستقلاً. S8: صوت الإغراء صراع داخلي لا كائن غيبي، فلا مؤثرات "شيطانية". الأساس عينة الشريحة (TASK-M08-011، TASK-M10-012).

## Implementation Plan
1. قائمة التسجيل: تصدير آلي لكل سطر معتمد (`approved`) من المقاطع وسطور الصوتين و`#main` مع `contentHash` وسياق السطر؛ لا يُسجل سطر غير معتمد.
2. اختيار الأصوات: راوٍ واحد بنبرة هادئة، وصوتا الضمير والإغراء متميزان (مثلاً نفس الجنس مع اختلاف الطبقة والإيقاع)، وأصوات الشخصيات الرئيسية؛ عقود تنقل حقوق الاستخدام. أي طفل مؤدٍّ بموافقة ولي أمره المكتوبة.
3. سياسة الآيات: الراوي لا يقرأ الآيات تمثيلاً؛ الافتراضي عرض نص الآيات صامتاً أو بتلاوة مسجلة مرخصة يعتمدها المراجع كبند مستقل. أي خيار غير الصمت يحتاج حكم المراجع قبل الدمج.
4. جلسات التسجيل بنص مطبوع من القائمة نفسها، مع مراجع لغوي للنطق والتشكيل.
5. المعالجة: تنظيف، وتسوية علو صوت موحدة لكل فئة (مقترح −18 LUFS للحوار)، وتسمية `vo.<audioKey>.<lineId>.wav`.
6. الدمج: ربط `audioKey` لكل سطر، وتخزين `recordedHash` بجانب الملف؛ `ContentValidator` يرفض في الإصدار أي ملف صوتي يختلف `recordedHash` فيه عن `contentHash` الحالي للنص.
7. مؤثرات الصوتين: معالجة خفيفة للتمييز (قرب، صدى بسيط) بلا تشويه مخيف وبلا موسيقى.
8. مزامنة الترجمة النصية الدائمة مع مدة كل ملف، ومستويات صوت منفصلة: الراوي، الأصوات الداخلية، البيئة (7.14).

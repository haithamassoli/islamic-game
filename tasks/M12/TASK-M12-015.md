## Objective
مجموعات السطور الكاملة لمحدد القواعد (FR-D2): barks لكل الشخصيات، وسطور الضمير والإغراء لكل المحفزات في PRD 7.6 عبر الفصول الثلاثة والنهاية واللعب الحر، بشروطها وأولوياتها ومهلاتها، وكلها `draft` حتى المراجعة.

## Description
v1 للصوتين (TASK-M07-017) غطى الشريحة. MVP يحتاج تغطية كاملة لكل محفز: قبل القرار، بعده، نجاح الغش دون كشف، الانكشاف أو الاتهام الباطل، المصيبة، خطوات التوبة، تأمل المساء، لقاء ضحية سابقة (7.6). القيود: FR-C2 (إشارة لأحداث فعلية)، FR-C3 (تتغير النبرة لا الحكم؛ آلية الضعف معطلة SR-01)، FR-C4، FR-C6، FR-C7، S7، S8، S10، FR-W6 (يشجع ولا يُيئس)، SR-12 (ذكر الله أو الأجر يمر بالمسار)، SR-13 (الإغراء لا يُشحن قبل الحسم). barks الشخصيات لا تتكلم في الدين (SR-10).

## Implementation Plan
1. مصفوفة تغطية: المحفزات الثمانية × الفصل × نمط اللاعب (أمين، غاش سري، منكشف، تائب، منتكس) × الصوت (ضمير/إغراء)؛ مع حد أدنى من السطور لكل خلية لضمان عدم التكرار ضمن المهلة.
2. حقائق إضافية تستخدمها الشروط: `story.act`، `family.strained_days` (TASK-M12-008)، `victim.departed` (TASK-M12-004)، `relationship.stage` (TASK-M12-006).
3. كتابة سطور الضمير: تذكير بحدث فعلي بمتغيرات (`{npc}`، `{day}`، `{amount}`) فقط من السجل؛ لا سببية للمصيبة، ولا مستقبل، ولا حكم بقبول.
4. كتابة سطور الإغراء: تبرير بشري داخلي (الحاجة، المنافسة، "لن يعرف أحد") يقترح خيارات اللعبة بمصطلحاتها فقط (S10)؛ لا يُقدَّم ككائن غيبي (S8).
5. سطور الضمير التي تذكر الله أو الأجر أو الرجاء توسم `sr: ["SR-12"]` وتحتاج `sourceIds` إن استشهدت بنص معتمد (F3: الضمير طبقة خارج الزمن يجوز له الاستشهاد بالمعتمد فقط). لا استخدام لحديث "التاجر الصدوق" (SR-06).
6. barks الشخصيات حسب السمات والمعتقدات (الزبونة تنقل، المورد يتجهم لمن يعتقده غشاشاً، كبير السوق يذكر الفحص).
7. سطور عامة احتياطية لكل محفز (FR-D5) خالية من أي مضمون ديني لتعمل حتى لو حُجبت السطور الموسومة.
8. التصدير للمراجع على دفعات (TASK-M08-008): دفعة لكل فصل لتقليل الانتظار.

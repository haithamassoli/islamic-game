## Objective
اختبارات الحفظ T3 وT4 وT6 (PRD 7.15) كاختبارات EditMode حتمية تعمل في CI مع T1 وT2 وT5 وT7 وT8 الموجودة، فتكتمل T1–T6 المطلوبة لبوابة P1.

## Description
بوابة P1 تشترط "نجاح الاختبارات من T1 إلى T6". T1/T7/T8 من [TASK-M01-015](../M01/TASK-M01-015.md)، وT2/T5 من [TASK-M05-017](../M05/TASK-M05-017.md). الباقي: **T3** (سيناريو كامل مع حفظ وتحميل في منتصفه وبدونه = الحالة النهائية نفسها)، و**T4** (حدث مؤجل يُنفَّذ مرة واحدة فقط عبر حدود الحفظ، FR-E5)، و**T6** (سطر `once` لا يتكرر بعد التحميل، [TASK-M03-010](../M03/TASK-M03-010.md)). الحدث المؤجل الحقيقي المستخدم هو اكتشاف الضحية في البيت ([TASK-M04-013](../M04/TASK-M04-013.md)). هذه الاختبارات تحرس FR-S2: التحميل استعادة لا إعادة تنفيذ.

## Implementation Plan
1. `Tests/EditMode/Save/ScenarioScript.cs`: سيناريو مبرمج كقائمة أفعال بزمن لعب (`At(day, minute, action)`): شراء، 4 بيوع أمينة، 2 غش بالصنجة لزبونة تزن في البيت، طلب حوار يُطلق سطراً، نوم. يُشغَّل على `SimulationWorld` مباشرة بمواقع شخصيات مبرمجة (لا NavMesh).
2. أداة `SaveRoundTrip.Through(world) → SimulationWorld`: تسلسل قانوني ← `ISaveStorage` في الذاكرة ← `SimulationWorld.Restore`.
3. **T3** `SaveTests.T3_MidScenarioSave_SameFinalState`: تشغيل A بلا حفظ حتى نهاية اليوم 2؛ تشغيل B بالبذرة نفسها مع حفظ/تحميل عند 3 نقاط آمنة (منتصف السوق، قبل النوم، بعد الاستيقاظ). المقارنة: نص JSON القانوني للقطتين النهائيتين متطابق بايتاً ببايت.
4. **T4** `SaveTests.T4_ScheduledEvent_ExecutesOnce`: غش يجدول `VictimDiscovery` بموعد D؛ حفظ عند D−60 دقيقة ← تحميل ← تقديم إلى D+10 ← حفظ ← تحميل ← تقديم إلى D+600. المتوقع: حدث الاكتشاف في السجل مرة واحدة، ومعتقد `VICTIM` واحد، والطابور لا يحوي العنصر.
5. **T4b** حالة الحافة: الحفظ عند `dueTime` تماماً بعد التنفيذ؛ التحميل لا يعيد التنفيذ (الحذف في الخطوة نفسها، FR-E5).
6. **T6** `SaveTests.T6_OnceLine_NotRepeatedAfterLoad`: محفز يُطلق سطراً `once` من [TASK-M06-002](../M06/TASK-M06-002.md) ← حفظ ← تحميل ← 50 طلباً بالمحفز نفسه والحقائق نفسها: السطر لا يعود. ومعه `T6_Cooldown_SurvivesLoad`: سطر مهلته 120 دقيقة قيل عند t؛ بعد التحميل لا يعود قبل t+120.
7. وسم كل اختبارات الحفظ بـ `[Category("SaveTests")]`؛ خطوة CI منفصلة تشغّل هذه الفئة وتُفشل البناء عند أي فشل، وتطبع جدولاً T1..T8 بالحالة.
8. عند فشل T3 يطبع الاختبار أول مسار JSON مختلف (مثلاً `memory.npcs[2].beliefs[0].confidence`) لتسريع التشخيص.

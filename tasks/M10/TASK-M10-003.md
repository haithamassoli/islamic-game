## Objective
واجهة HUD مختصرة RTL تعرض فقط: المال، واليوم والوقت، وتلميح التفاعل، ومؤشر الطبقة، ومؤشر الحفظ؛ دون أي عداد أو شريط أو رقم للأخلاق أو الإيمان أو السمعة (S9، FR-L2).

## Description
S9: "لا شيء يمثل صحيفة أعمال... ولا عدادات للحسنات أو السيئات أو للإيمان". FR-L2: السجل الأخلاقي لا يظهر أبداً كرقم أو شريط. قاعدة التصميم DR-04 في [docs/GDD.md](../../docs/GDD.md). السمعة تُستشعر من سلوك الناس (عدد الزبائن، الأسعار، الحوار، FR-R3) لا من مؤشر. الحد الأدنى المقبول للشريحة: المال والوقت (PRIORITIES).

## Implementation Plan
1. `Runtime/UI/Hud/HudScreen.cs` بمكونات [TASK-M10-001](../M10/TASK-M10-001.md): المال (`UiFormat.Money`) أعلى اليمين، اليوم والوقت بجانبه، تلميح التفاعل أسفل الوسط، مؤشر الطبقة ([TASK-M08-010](../M08/TASK-M08-010.md)) أعلى اليسار، ومكان مؤشر الحفظ ([TASK-M10-013](../M10/TASK-M10-013.md)).
2. مصادر البيانات بقراءة مباشرة: المال من `Economy` لمحفظة اللاعب، الوقت من `GameClock`. التحديث عند `OnRecorded` (للمال) وكل دقيقة لعب (للوقت)، لا كل إطار.
3. تغير المال يظهر كإشارة صغيرة (+/−) لثانيتين **دون** تمييز لوني بين ربح حلال وربح غش (لا يكشف الحكم ولا يكافئه).
4. حارس معماري: اختبار انعكاسي يفشل إن احتوى أي صنف في `Runtime/UI/Hud` حقلاً أو استدعاءً لأنواع `MoralLedger` أو `TruthAxisState` أو `ReputationModel`.
5. وضع إخفاء HUD (للقطات) يخفي كل شيء ما عدا مؤشر الطبقة والترجمة النصية.
6. الحجم يتبع إعداد حجم النص؛ العناصر لا تغطي منطقة الميزان أثناء تفاعل الوزن ([TASK-M04-006](../M04/TASK-M04-006.md)).

## Acceptance Criteria
- [ ] HUD يعرض المال والوقت بدقة: المال = محفظة الاقتصاد بعد كل صفقة (10 صفقات اختبار).
- [ ] الاختبار المعماري ينجح: صفر مرجع لأنواع الأخلاق/محور الحقيقة/السمعة داخل `Runtime/UI/Hud`.
- [ ] مراجعة لقطات: لا شريط أو رقم أو أيقونة تمثل أخلاقاً أو إيماناً أو سمعة.
- [ ] إشارة تغير المال متطابقة بصرياً لصفقة أمينة وصفقة غش بنفس المبلغ.
- [ ] HUD لا يغطي الميزان أثناء الوزن على دقة 1280×720 و2560×1600.
- [ ] كلفة HUD ≤ 0.3 ms لكل إطار على M1.

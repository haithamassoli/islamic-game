## Objective
شاشة إعدادات RTL تحفظ تفضيلات اللاعب خارج ملفات الحفظ: مستويات صوت منفصلة، وحجم الترجمة وخلفيتها (دون إمكانية تعطيلها)، وإعادة تعيين الأزرار، ووضع عمى الألوان، وجودة الرسوم.

## Description
PRD 7.14: ترجمة نصية دائمة لكل صوت وحجم نص قابل للتعديل، ومستويات صوت منفصلة (البيئة، الراوي، الأصوات الداخلية)، وإعادة تعيين أزرار التحكم، ووضع ألوان لعمى الألوان، وإعدادات جودة الرسوم. FR-C5: ترجمة دائمة للصوتين الداخليين. ملف Input Actions القابل لإعادة التعيين من [TASK-M02-001](../M02/TASK-M02-001.md). الإعدادات ليست حالة محاكاة فلا تدخل لقطة الحفظ ولا تمس الحتمية.

## Implementation Plan
1. `Runtime/Settings/SettingsData.cs` (صنف عادي): `masterVol`، `ambienceVol`، `narratorVol`، `innerVoicesVol`، `dialogueVol`، `sfxVol`، `uiVol` (0–100)، `textScale` (100/125/150)، `subtitleBgOpacity` (40–100)، `layerIndicatorOpacity`، `colorMode` (Normal/ProtanDeutan/Tritan)، `qualityTier` (Low/Medium/High)، `bindingOverridesJson`، `schemaVersion`.
2. `SettingsStore`: JSON في `Application.persistentDataPath/settings.json` بكتابة ذرية، منفصل عن خانات الحفظ؛ قيم افتراضية عند الغياب أو التلف.
3. الصوت: ربط القيم بمعاملات المكسر المكشوفة من [TASK-M10-011](../M10/TASK-M10-011.md) (تحويل خطي إلى dB، و0 = −80 dB).
4. الترجمة: لا مفتاح تعطيل للترجمة إطلاقاً؛ الحجم والخلفية فقط. حجم النص يُطبق عبر المتغير الجذري في [TASK-M10-001](../M10/TASK-M10-001.md) وعلى `AyahView` بحد أدنى.
5. إعادة التعيين: واجهة `InputActionRebindingExtensions` لكل إجراء في الخريطة، مع كشف التعارض وزر "استعادة الافتراضي"، والحفظ عبر `SaveBindingOverridesAsJson`.
6. عمى الألوان: تبديل لوحة الرموز وقت التشغيل + ألوان تمييز الصوتين الداخليين وعلامات التفاعل.
7. الجودة: ثلاثة أصول URP Pipeline (ظلال، دقة عرض، MSAA، كثافة التفاصيل)؛ Medium هو هدف 60 fps على M1.
8. معاينة فورية لكل تغيير، وزر "تطبيق" غير مطلوب. الشاشة متاحة من القائمة الرئيسية وقائمة الإيقاف.

## Acceptance Criteria
- [ ] سبعة منزلقات صوت مستقلة، وكل منها يغير مجموعة مكسر واحدة فقط (اختبار لكل منزلق).
- [ ] لا يوجد أي إعداد يعطل الترجمة النصية (فحص `SettingsData` + اختبار).
- [ ] الإعدادات تبقى بعد إعادة التشغيل، وملف تالف يعود للافتراضي دون تعطل.
- [ ] تغيير الإعدادات لا يغير بايتاً في ملف الحفظ (T1 مع وبدون تغيير الإعدادات).
- [ ] إعادة تعيين كل إجراءات الخريطة تعمل، والتعارض يُعرض ويُمنع.
- [ ] الجودة Medium تحقق 60 fps في مشهد السوق على M1 (قياس مرفق، أو يُحال إلى [TASK-M11-003](../M11/TASK-M11-003.md) إن لم يكتمل الفن).
- [ ] كل النصوص بمفاتيح والتخطيط RTL.

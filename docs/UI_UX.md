## 4. التحكم
منصة MVP هي macOS بلوحة مفاتيح وفأرة؛ اللمس بعد قرار المنصة (P4).

### 4.1 لوحة المفاتيح والفأرة (MVP)
ملف Input Actions قابل لإعادة التعيين بالكامل ([TASK-M02-001](../tasks/M02/TASK-M02-001.md)). المفاتيح تُربط **بالموضع الفيزيائي** لا بالحرف، فتعمل مع لوحة المفاتيح العربية.

| الفعل | الافتراضي *(مقترح)* | ملاحظة |
|---|---|---|
| الحركة | W A S D | — |
| النظر والكاميرا | الفأرة | حساسية وعكس المحور في الإعدادات |
| الركض | Shift | ضغط مستمر أو تبديل (إعداد) |
| التفاعل | E | التلميح يعرض المفتاح المعيَّن فعلاً |
| تقديم الحوار | Space أو النقر | — |
| اختيار رد | النقر أو 1–4 | الأرقام بالترتيب من اليمين |
| الميزان: وضع ورفع | سحب بالفأرة، أو تحديد بالأسهم ثم E | بديل لوحة المفاتيح كامل لمن لا يستطيع السحب |
| قائمة الإيقاف | Esc | — |
| إخفاء HUD | H | — |

### 4.2 اللمس (بعد MVP)
التصميم في [TASK-M14-002](../tasks/M14/TASK-M14-002.md). مبادئ مسبقة: أهداف لمس كبيرة، والميزان بالنقر لا بالسحب الدقيق، ولا إيماءات متعددة الأصابع إلزامية، وكل الأفعال متاحة بلمسة واحدة. لا يُبنى قبل قرار المنصة ([TASK-M14-001](../tasks/M14/TASK-M14-001.md)).

## 7. عرض الصوتين الداخليين وطبقة القصة
- **الصوتان** (FR-C5): لكل صوت موضع ثابت على الشاشة وإطار وملمس مختلف واسم ظاهر، إضافة إلى الصوت المسجل المختلف. *(مقترح)* لا ترميز "أحمر شرير / أخضر خيّر": التمييز بالموضع والشكل لا بلون أخلاقي. لا أيقونة شيطان أو ملاك أو جناح أو قرون (S1، S8).
- السطر الداخلي لا يغطي خيارات الحوار ولا الميزان، ويختفي بعد مدة قراءة كافية تتناسب مع حجم النص *(مقترح)*، ويمكن إعادة قراءته من سجل السطور.
- **طبقة القصة**: لوحة ألوان وإضاءة مختلفة، وانتقال واضح، ومؤشر الطبقة ([TASK-M08-001](../tasks/M08/TASK-M08-001.md)). لا واجهة لعب (لا مال ولا HUD) أثناء المقطع.

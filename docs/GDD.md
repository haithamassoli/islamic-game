# وثيقة تصميم اللعبة (GDD)

> مسؤولية هذه الوثيقة: **محور** تصميم اللعب. تعرّف الخيال الجوهري ودور اللاعب، وتربط الأنظمة بوثائقها، وتحدد نطاق كل مستوى (Prototype / Vertical Slice / MVP) ومعايير نجاحه القابلة للقياس، وقواعد التصميم العامة. المتطلبات الملزمة في [PRD](PRD.md)؛ هذه الوثيقة لا تكررها بل تفصّلها.

## 1. الخيال الجوهري (Core Fantasy)
> "أنا تاجر في سوق حي. الميزان بيدي، وأسرتي تحتاج المال، والصنجة الأخرى في الدرج. لا أحد ينظر الآن… أو هكذا أظن."

ثلاثة أحاسيس يجب أن تتحقق في كل جلسة:
1. **الملموسية:** البيع فعل جسدي بالميزان (FR-T2)، لا قائمة أرقام.
2. **العالم يتذكر:** كل شخصية تعرف ما رأته أو سمعته فقط (FR-M1)، والأخبار تنتقل وتتشوه (FR-M3).
3. **القرار لي وحدي:** لا شيء يمنعني، ولا شيء يجبرني (FR-C4)، والنتائج تنبع مما فعلت ومما ظنه الناس.

## 2. دور اللاعب
| الجانب | التصميم |
|---|---|
| الهوية | تاجر شاب (ذكر أو أنثى، SR-08) في بلدة خيالية (F1)، له دكان وبيت وأسرة. انظر [CHARACTER_DESIGN.md](CHARACTER_DESIGN.md). |
| الدافع | إعالة الأسرة وتوسيع الدكان (PRD §5.3). الحلال ممكن دائماً لكنه أبطأ. |
| الأفعال الأساسية | المشي والتفاعل، الشراء من الموردين، التسعير، البيع بالميزان، الحوار، المساعدة والصدقة، طلب التبرئة، الندم والإقلاع ورد الحقوق، زيارة نقاط السرد. |
| ما لا يفعله | لا قتال، لا سرقة يرتكبها اللاعب، لا ربا ولا قروض (PRD §3)، لا تغيير لطبقة القصة (S2). |
| الكاميرا والتحكم | شخص ثالث (Cinemachine)، لوحة مفاتيح وفأرة. انظر [UI_UX.md](UI_UX.md). |

## 3. الركائز
مرجعها [VISION.md §4](VISION.md): التعلم بالعواقب، الحقيقة مقابل السمعة، لا تجسيد للأنبياء، فصل الخيال عن الطبقة القرآنية.

## 5. نطاق المحتوى حسب المستوى
ثلاثة مستويات منفصلة، لكل منها بوابة خروج. الأرقام المعلّمة بـ *(مقترح)* أهداف تصميمية تُثبَّت في مهمة بروتوكول الاختبار المذكورة؛ ما عداها من PRD §11–12.

### 5.1 النموذج الأولي (Prototype) — M02–M06، يقابل P1
**السؤال الوحيد:** هل الحركة والتفاعل والتجارة البسيطة والإغراء ممتعة **بلا رسوم**؟

| المحتوى | المقدار |
|---|---|
| العالم | Graybox: السوق (دكان اللاعب، دكان المنافس، الميزان العام، البئر)، بيت اللاعب، حي سكني ([TASK-M02-005](../tasks/M02/TASK-M02-005.md)، [TASK-M02-006](../tasks/M02/TASK-M02-006.md)) |
| الشخصيات | 3: التاجر المنافس، كبير السوق، الزبونة ([TASK-M03-011](../tasks/M03/TASK-M03-011.md)) + زبائن عامّون |
| الأنظمة | الحركة والكاميرا، التفاعل، الميزان والصنجات، الشراء والبيع، طرق الغش (FR-P3)، السجل، الشهود، المعتقدات والشائعات، السمعة، اتهام باطل واحد، يوم كامل بحفظ تلقائي |
| النصوص | 30 سطراً مؤقتاً للضمير والإغراء **بلا أي نص ديني** ([TASK-M06-002](../tasks/M06/TASK-M06-002.md)) |
| ليس فيه | رسوم نهائية، صوت مسجل، طبقة القصة، التوبة، النهايات |

**معايير النجاح (بوابة [TASK-M06-008](../tasks/M06/TASK-M06-008.md)، 5 أطفال أو أكثر):**
| المعيار | العتبة |
|---|---|
| الحركة والتفاعل مفهومان: يصل الطفل للدكان ويُتم أول بيع دون مساعدة | ≥ 80% خلال 5 دقائق *(مقترح)* |
| التجارة ممتعة: تقييم "البيع بالميزان" | متوسط ≥ 3.5 من 5 *(مقترح)* |
| الإغراء مغرٍ (PRD P1): الطفل غش مرة على الأقل أو صرّح بأنه فكّر جدياً في الغش | ≥ 60% *(مقترح)* |
| الانكشاف عادل ومفهوم (PRD P1): من انكُشف يشرح من رآه ولماذا | ≥ 70% *(مقترح)* |
| الاتهام الباطل عادل ومفهوم (PRD P1): يميّز أنه اتُّهم بما لم يفعل ويعرف مسار التبرئة | ≥ 70% *(مقترح)* |
| الاستقرار | جلسة 20 دقيقة بلا انهيار، ونجاح T1–T6 في CI |

بروتوكول القياس: [TASK-M06-007](../tasks/M06/TASK-M06-007.md). قرار الاستمرار: [TASK-M06-009](../tasks/M06/TASK-M06-009.md).

### 5.2 الشريحة العمودية (Vertical Slice) — M07–M11، يقابل P2
**السؤال:** هل نصل لجودة الإصدار في 10–15 دقيقة مصقولة، وكم يكلف MVP؟

| المحتوى | المقدار |
|---|---|
| العالم | منطقة السوق بالجودة النهائية: أصول، إضاءة URP، بيئة صوتية ([TASK-M10-007](../tasks/M10/TASK-M10-007.md)، [TASK-M10-009](../tasks/M10/TASK-M10-009.md)، [TASK-M10-010](../tasks/M10/TASK-M10-010.md)) |
| الشخصيات | 3 شخصيات النموذج + من يحتاجه السيناريو (مقترح: التاجر الأمين المسن، الصبي الحمّال، المورّد)؛ يُثبَّت في [TASK-M11-001](../tasks/M11/TASK-M11-001.md) |
| اللعب | يوم كامل من الحلقة اليومية، مسار توبة كامل (ندم، إقلاع، رد حق)، مقطع قصة الفصل الأول معتمد، نهايتان، مراجعة رحلة من بيانات حقيقية |
| الصوت | عينة تسجيل عربي: الراوي للفصل الأول، والصوتان الداخليان ([TASK-M08-011](../tasks/M08/TASK-M08-011.md)، [TASK-M10-012](../tasks/M10/TASK-M10-012.md)) |
| الواجهة | القائمة الرئيسية، خانات الحفظ، HUD، الإعدادات، إنشاء الشخصية |

**معايير النجاح (بوابة M11):**
| المعيار | العتبة |
|---|---|
| مدة الشريحة | الوسيط بين 10 و15 دقيقة، و≥ 80% يكملونها *(مقترح)* |
| الجودة المقبولة (PRD P2) | ≥ 70% من المختبرين يقيّمون المظهر والصوت بـ "مقبول" أو أعلى *(مقترح)*، [TASK-M11-006](../tasks/M11/TASK-M11-006.md) |
| فهم مسار التوبة | ≥ 70% ممن غشوا يجدون طريق رد الحق دون مساعدة *(مقترح)* |
| فصل الطبقتين | ≥ 80% يميزون أن البلدة خيال وأن المقطع خبر قرآني *(مقترح)* |
| FR-J8 | ينجح آلياً ([TASK-M09-006](../tasks/M09/TASK-M09-006.md)) |
| الأداء | 60 إطاراً على Mac M1 بإعدادات متوسطة ([TASK-M11-003](../tasks/M11/TASK-M11-003.md))، وإعادة قياس الويب والجوال ([TASK-M11-004](../tasks/M11/TASK-M11-004.md)) |
| المحتوى الديني | صفر عنصر غير `verified`+`approved` في البناء ([TASK-M11-005](../tasks/M11/TASK-M11-005.md)) |
| الكلفة | تقدير مكتوب لكلفة MVP ([TASK-M11-007](../tasks/M11/TASK-M11-007.md)) |

### 5.3 MVP — M12–M13، يقابل P3
**السؤال:** هل لدينا إصدار مكتمل يحقق معايير PRD §12؟

| المحتوى | المقدار |
|---|---|
| العالم | البلدة كاملة: السوق، الأحياء، طريق القوافل، البئر والمراعي، نقاط السرد ([TASK-M12-001](../tasks/M12/TASK-M12-001.md)) |
| الشخصيات | الأدوار الإحدى عشرة (PRD §5.2) بسماتها وجداولها ([TASK-M12-003](../tasks/M12/TASK-M12-003.md)) |
| القصة | قصة رئيسية 60–90 دقيقة: البداية، الفصول 1–3، النهاية بترتيب F5، ثم لعب حر |
| النهايات | الثماني كاملة (PRD §7.11) |
| مقاطع القصة | الأربعة (F4) معتمدة |
| الصوت | تسجيل عربي كامل للراوي والصوتين والسطور الرئيسية |
| الواجهة | كل الشاشات والإعدادات وإمكانية الوصول (PRD §7.14) |

**معايير النجاح:** كل بنود PRD §12 كما هي (إتمام القصة 60%، شرح حرمة الغش 70%، فهم "الأمين المظلوم" 70%، إعادة اللعب 40%، الضمير غير مزعج 70%، موافقة الأهل 80%، صفر محتوى ديني غير معتمد وصفر مسائل معلقة مفعّلة، 60 إطاراً على M1، FR-J8، T1–T9 وصفر فقدان حفظ)، إضافة إلى:
| المعيار | العتبة |
|---|---|
| مدة القصة الرئيسية | الوسيط بين 60 و90 دقيقة في اختبار [TASK-M13-006](../tasks/M13/TASK-M13-006.md) *(مقترح)* |
| تنوع النهايات | كل نهاية من الثماني قابلة للوصول في اختبار مبرمج ببذرة ثابتة *(مقترح)* |

## 6. قواعد التصميم (Design Rules)
تنطبق على كل ميزة وكل محتوى. المخالفة تُعامل كعطل.

| # | القاعدة | المرجع |
|---|---|---|
| DR-01 | كل نتيجة يراها اللاعب لها حدث في السجل. لا عاقبة بلا `causeEventIds` محسوبة، ولا رقم في المراجعة بلا دليل. | FR-E3، FR-J2 |
| DR-02 | لا خيار يُمنع ولا يُفرض. خيار الغش وخيار الأمانة متساويان في الوزن البصري وفي سهولة الوصول. | FR-C4 |
| DR-03 | الحلال ممكن دائماً. الأمين لا يُحبس في طريق مسدود اقتصادياً. | PRD §5.3، FR-T5 |
| DR-04 | لا رقم أخلاقي ظاهر. السجل الأخلاقي يظهر فقط عبر نبرة الضمير والنهاية. | S9، FR-L2 |
| DR-05 | المصيبة ليست عقوبة. أحداث الحياة بمعدل واحد، ولا تُربط بذنب في أي نص أو مراجعة. | FR-K2، FR-K3، FR-J5، S7 |
| DR-06 | كل ما تعرفه الشخصية له مصدر (شهود، ضحية، سماع، خطأ، بهتان). السمعة لا تقرأ السجل. | FR-M1، FR-R2 |
| DR-07 | الصمت هو الافتراض. الضمير يتكلم عند المحفزات فقط وبمهلات؛ تقليل السطور أفضل من الوعظ. | FR-D5، PRD §13 |
| DR-08 | طبقة القصة لا تتأثر بشيء، والفصول تفتح المقاطع فقط. | S2، FR-N1 |
| DR-09 | كل نص بمفتاح ترجمة، وكل نص ديني يمر بالمرحلتين قبل البناء. | §7.14، S12، FR-Q1 |
| DR-10 | الأنظمة العامة لا تعرف التجارة؛ التجارة تتصل بها عبر الأحداث. | PRD §8.5 |
| DR-11 | ميزة مرتبطة بمسألة SR معلقة تعمل بالسلوك المحايد حتى الحسم. | FR-Q5، PRD §10 |
| DR-12 | الإغراء يقترح فقط ما هو موجود في اللعبة، بمصطلحات اللعبة. | S10 |
| DR-13 | التوبة متاحة دائماً، والنص لا يحكم بقبولها. | FR-W6، FR-X3 |
